# Changelog

All notable changes to this document are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow the rules in stage 4 of
this procedure. The newest entry is the document's current version and its date is the approval date.

## [1.2.0] - 2026-07-06

### Added

- Stage 6: publication as digitally signed PDFs with a SHA-256 manifest on every release, replacing
  the manual intranet upload.
- Stage 5: automated review-due issues sixty days before the review date.

### Changed

- Stage 3: approver matrix extended to documents limited to PaketPort Deutschland GmbH and
  PaketPort Software s.r.o.; control guides are approved by the control owner with the ISMS Manager
  as second reviewer.

## [1.1.0] - 2025-11-17

### Added

- Stable statement ids for policy statements and standard requirements (authoring guide).
- Stage 7: retirement and supersession rules, including the RETIRED watermark.

### Changed

- Stage 5: a periodic review without changes is now recorded as a PATCH version instead of a note
  in the document register.

## [1.0.0] - 2025-06-02

### Added

- Initial approved version: migration of the ISMS document set from the document management
  system to the version-controlled repository, with pull-request review as the approval record.
