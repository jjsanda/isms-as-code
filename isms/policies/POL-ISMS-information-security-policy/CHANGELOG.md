# Changelog

All notable changes to this document are recorded here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow the rules in PROC-DOC.
The newest entry is the document's current version and its date is the approval date.

## [2.0.0] - 2025-09-01

### Changed

- Rewritten for ISO/IEC 27001:2022 and the NIS2 Directive; the scope now covers the group
  (PaketPort Systems GmbH, PaketPort Deutschland GmbH, PaketPort Software s.r.o.) instead of the
  Austrian entity alone.
- ISMS-2 now carries the objectives table with measures and targets agreed at the management review.
- Statement ids ISMS-1 to ISMS-12 introduced; ISMS-8 lists the topics of the policy framework.

### Removed

- The detailed description of roles, committees and reporting lines, which moved to POL-ORG.

## [1.2.0] - 2024-09-02

### Changed

- Periodic review: references to the ISO/IEC 27001:2013 control set replaced by the 2022 Annex A;
  NIS2 preparation added to the management commitment; objectives for 2024/25 updated.

## [1.1.0] - 2023-09-04

### Added

- Duty of all staff to report suspected security events through the incident channels.

### Changed

- Objectives for 2023/24 updated following the first internal audit.

## [1.0.0] - 2022-09-05

### Added

- Initial approved version (imported from the previous document management system).
